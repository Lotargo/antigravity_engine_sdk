# Независимый Supercomplete

Дата: 2026-10-21. Go SDK 0.5.0, native 2.24.0.

`EditorSession.Supercomplete` можно вызывать в любой момент после `Sync`,
включая единственный снимок без истории правок. Метод использует общую с
`TabToJump` подготовку: отдельный временный native процесс, пустой служебный
документ с фактическим epoch mtime, bootstrap без генерации и загрузку
фактических снимков пользователя. Затем выполняется один реальный запрос
SUPERCOMPLETE с моделью `tab_flash_lite_preview` из свежего каталога.

Механизм bootstrap и ограничение native 2.24.0 описаны в
[исследовании Tab-to-Jump](INDEPENDENT-JUMP-2026-10-21.md).
Bootstrap frames/terminal и оригинальные ObservedAt сохраняются отдельно.
Другие версии отклоняются до bootstrap; неожиданные данные bootstrap
останавливают вызов. История пользователя и его код не подделываются.

Исходный автоматический путь сохранён как `SupercompleteNative`.
Для автоматической пары вызывайте `SupercompleteNative` → `TabToJumpNative`;
ручные методы используют отдельные процессы и не подготавливают эту пару.
Отмена context и закрытие сессии прерывают активный запрос. Незавершённый
или устаревший diff нельзя применить через `Preview`.

## Результаты проверки

CLI: `go run ./testbench --live --case supercomplete --editor-idle 65s`.
В первом прогоне реальные снимки были синхронизированы до паузы 65000 мс.
Supercomplete вернул `edit`, 2 data frames, за 5050 мс; bootstrap занял
2 мс и вернул только terminal `{}`. Предпросмотр совпал с нативным diff.
Модель предложила `a - b` для функции `add`: запуск и контракт подтверждены,
семантическое качество этой подсказки неудовлетворительно. Автоприменения нет.
Raw: `reports/supercomplete-independent-go-2026-10-21-01/editor-report.json`.

В браузере дополнительно проверен единственный неизменённый снимок:
исходный и текущий текст `def add(a, b):\n    return \n` одинаковы.
Supercomplete вернул `return a + b`, статус `edit`, 2 кадра, 4565 мс;
bootstrap 2 мс без data frames. Подтверждены отмена (`incomplete`, 0 кадров)
и повторный запуск без новой правки. В сценарии с удалением готового выражения
native также возвращал `filtered: revert command`; это сохраняется буквально.
Raw UI: `reports/go-live-20261021-195126.488656500/editor-*.json`.

Регрессии проверяют оба вида запросов, выбор модели, один реальный model
request, отсутствие генерации при bootstrap, старые ObservedAt, один снимок,
пустой/filtered ответ, отмену и восстановление, запрет неожиданного bootstrap
и неподдержанной версии. `go test ./...`, `go test -race ./...`, `go vet ./...`
прошли. Usage и точная атрибуция реально выбранной модели остаются UNKNOWN.

Второй CLI-прогон проверяет финальный пример без истории правок: исходный и
текущий тексты одинаковы, сохранён один снимок, пауза 65000 мс. Результат
`edit`, 2 кадра, 3818 мс; точный предпросмотр `return a+b`. Bootstrap
вернул terminal `{}` без data frames.
Raw: `reports/supercomplete-independent-go-2026-10-21-02/editor-report.json`.

## Стенд

`go run ./testbench --live --ui --listen 127.0.0.1:8769`, страница `/editor`.
Кнопка «Загрузить пример дополнения» подготавливает одинаковые версии
незавершённой функции. После «Запомнить исходную версию» можно ждать сколько
угодно и нажимать Supercomplete, просматривать diff, применять или отменять.
Tab-to-Jump остаётся отдельной командой.
