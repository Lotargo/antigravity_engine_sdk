# Общий стенд: выбор Python / Go SDK

Дата: 2026-10-21.

Один origin обслуживает чат и редактор, переключатель выбирает реальный backend
для всех API запросов. Python launcher запускает отдельный Go testbench на
случайном loopback-порту. Существующие стенды на 8772/8773 сохранены; новая
проверенная версия открыта на `http://127.0.0.1:8774/editor`.

Выбор SDK сохраняется при переходе между страницами в той же вкладке.
Текущий код/курсор, baseline, язык/имя файла, промпт, доступный в обоих каталогах
ID модели, формат ответа и вложение не сбрасываются при выборе другого SDK.
Сессии и последние результаты каждого SDK раздельны; результат показывает SDK,
версию и длительность. Кэш редактора живёт до перезагрузки страницы. Переключение
заблокировано во время подготовки, обновления каталога и генерации. Завершение
или отмена освобождает выбор. При остановке Go возвращается явная ошибка без
Python fallback.

## Проверки

- Python: **100 passed**; включая проксирование JSON/multipart, замену credentials,
  маршруты отмены/отчётов, раздельное состояние, Host/Origin/token guards,
  неизвестный/остановленный SDK и отсутствие fallback. Отдельный тест действительно
  запускает собранный Go backend без inference, проверяет handshake и завершение
  принадлежащего ему процесса (пропускается, если binary ещё не собран).
- Go `go test ./testbench`: успешно; в том числе каталог backend и отказ
  standalone Go обслуживать запрос, помеченный как Python.
- Ruff: успешно. Нативный движок: **2.24.0**. Версии SDK: Python **0.2.0**,
  Go **0.5.0**. Исходники SDK в этом изменении не менялись.
- Живой Supercomplete на одинаковом тексте `def add(a, b):\n    return \n`,
  одинаковый UTF-8 cursor offset **26**: Python `edit`, **4812 мс**;
  Go `edit`, **3953 мс**. Курсор и код сохранились при переключении; после возврата
  восстановился исходный результат соответствующего SDK. Это отдельные наблюдения,
  а не измерение сравнительной скорости моделей или SDK.
- Один и тот же красный PNG, промпт и `gemini-3.8-flash-low` через `chat()`:
  Python и Go ответили «Красный». При переключении сохранились файл, промпт,
  модель и формат; при возврате восстановился ответ Python.
- Go chat через gateway отменён на фазе «Модель готовит ответ…»; переключатель
  был заблокирован до завершения отмены. Следующий `complete()` завершился.
  `tab_flash_lite_preview` вернул текст с буквальными `\\n` и XML-подобным хвостом;
  содержимое сохранено без исправления. Успех транспорта не означает качество кода.
