# Python SDK 0.2.0: общий стенд и нативный редактор

Дата: 2026-10-21.

Python backend находится в `python/testbench/server.py`, использует Python SDK
напрямую и обслуживает те же локальные ресурсы интерфейса, что Go backend.
Для запуска Go не требуется. Python-стенд проверен на `127.0.0.1:8773`, редактор
на `/editor`. Ранее запущенные Go-стенды сохранены.

## Изменения и локальная регрессия

- `Client.complete()` возвращает буквальный planner text без инструментов.
  Строгий `finish` у `chat()`/`generate()` сохранён без fallback.
- `EditorSession` возвращает native diff, позицию курсора, исходные кадры,
  terminal и данные подготовки контекста. Независимые команды используют
  изолированный процесс, нулевой по inference bootstrap и последние реальные
  снимки. Автоматические `*_native()` методы доступны отдельно.
- Проверены UTF-8 offsets, UTF-16 позиции, точное совпадение исходника при preview,
  Unicode/CRLF, остановка блокирующего чтения, дедлайны, частичные ответы,
  закрытие, повторный запрос после отмены, ошибки протокола и version guard.
- Исправлена классификация короткого request timeout и доступ concurrent metadata
  к ещё не прошедшему авторизацию процессу. Добавлены отдельные регрессии.
- Полный Python набор: **91 passed**. Ruff: без ошибок.
  Go `go test ./testbench`: успешно после общей параметризации подписи SDK.
- Wheel `antigravity_engine_sdk-0.2.0-py3-none-any.whl` собран; проверены metadata,
  включение `editor.py`/`_stream.py` и импорт непосредственно из wheel.
  Нативный executable и ресурсы тестового стенда в пакет не входят.

## Живые проверки

Установленный native: **2.24.0**. Независимая подготовка разрешена только для
этой проверенной версии; неожиданное содержимое bootstrap останавливает запрос.

| Проверка | Наблюдение |
| --- | --- |
| Каталог, выбор модели | Получен текущий каталог аккаунта через Python backend |
| Vision через `chat()` | `gemini-3.8-flash-low`, контролируемый красный PNG: ответ «Красный» |
| Текст через `complete()` | `tab_flash_lite_preview`: код `return a + b` в буквальном fenced block, без finish |
| Отмена chat и восстановление | Длинный запрос отменён; следующий завершился ответом «Python работает» |
| Supercomplete, загрузка и скачивание | Загружен UTF-8 файл с кириллицей и emoji; получена правка `return a + b` с дополнительным `print`; применённый скачанный файл побайтно совпал с preview |
| Supercomplete после паузы | Один неизменённый снимок, реальный idle 65 секунд; получен edit, 2 кадра, bootstrap без data frames |
| Отмена editor и восстановление | Команда отменена; повтор завершился штатным filtered результатом |
| Отдельный Tab-to-Jump | После финального перезапуска Python-стенда: jump `row=28, col=21`, 3 кадра; UI перешёл на строку 29, столбец 22 и выделил цель |

Проверка после 65 секунд подтверждает доступность ручного запуска, а не качество:
native предложил `return 11`. Ранее Tab-to-Jump также возвращал filtered с причиной
`No changed lines found beyond minimum distance threshold`. Ответы сохранены
буквально; автоматической замены или исправления предложений нет. Native editor
RPC не сообщает токены: usage остаётся **UNKNOWN**, выбранный catalog/native ID
не считается доказательством фактически обслужившей модели.
