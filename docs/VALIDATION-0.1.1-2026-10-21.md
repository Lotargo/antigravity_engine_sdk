# SDK 0.1.1: concurrent metadata RPC

Дата: 2026-10-21.

При подключении VEIL обнаружено различие: исходный адаптер позволял читать
каталог моделей во время inference, а SDK 0.1.0 сериализовал все вызовы клиента.
В 0.1.1 добавлен `Client.rpc(..., concurrent=True)` для независимых metadata
запросов на уже работающем движке. Обычный RPC и high-level генерации сохраняют
прежнюю сериализацию. Холодный запуск проходит через общий ownership lock.

Добавлен boundary-регрессионный тест: незавершённая генерация продолжает работать,
каталог прочитан за отдельный короткий интервал, второй процесс не запущен,
после этого генерация отменена и процесс очищен. В VEIL отдельный регрессионный
тест сначала воспроизвёл задержку на 0.1.0. Native проверка интеграции документируется
в репозитории VEIL отдельно от исходного SDK smoke 0.1.0.
